# 杭客松奖金分发与荣誉机制（核心机制）

本文是杭客松平台机制的唯一定义，代码中的数值以本文为准（`lib/contribution.ts` 的 `MECHANISM` 常量）。
适用于所有**有奖金**的赛事（奖金总额 > 0 且设奖）；无奖金活动同样累计贡献值与荣誉，只是不分发奖金。

## 阶段流

**报名 → 阵营选择 → 正式阶段 → 结算**

1. **报名**：用户在杭客松平台报名参加一个活动。
2. **阵营选择**：报名后进入阵营选择阶段，从杭州行政范围的**十区两县一市**共 13 个阵营中选择一个加入（十区：上城、拱墅、西湖、滨江、萧山、余杭、临平、钱塘、富阳、临安；两县：桐庐、淳安；一市：建德）。**阵营在该活动内锁定，后续无法更改。**
3. **正式阶段**：按阵营竞争，产出、审核、累计贡献值（见下）。
4. **结算**：活动结束后分发奖金、折算荣誉。

## 算力券（正式阶段的参与激励）

- 每位用户每天收到面额 **¥100** 的算力券，**当日有效，过期作废**。
- 每成功邀请一位新用户，每日算力券面额 **+¥5**，封顶 **¥200/天**（即最多计 20 位邀请）。
- 算力券用于正式阶段内调用平台算力与提交产出物。

## 贡献值（竞争与分奖的依据）

- 用户提交的产出物在 **24 小时内**经过平台质量审核，按质量档位获得**个人贡献值**（在单个活动内累加）：

  | 档位 | 贡献值 |
  | --- | --- |
  | 优 | 100 |
  | 良 | 60 |
  | 合格 | 30 |
  | 未通过 | 0 |

- 每日最多 **3 份**有效提交。
- **阵营贡献值 = 该阵营所有成员的个人贡献值之和。**
- 活动详情页展示所有阵营总贡献值、每个阵营的贡献值与占比（饼状图）。

## 奖金分发（两层按比例）

设活动奖金池为 `P`，阵营 `i` 的贡献值为 `Cᵢ`，总贡献值为 `C = ΣCᵢ`：

- **阵营奖金**：`Pᵢ = P × (Cᵢ / C)` —— 饼图占比即奖金占比。
- **个人奖金**：阵营 `i` 中成员 `j` 获得该阵营内按个人贡献的比例份额：
  `Dᵢⱼ = Pᵢ × (cᵢⱼ / Cᵢ)`（`cᵢⱼ` 为成员个人贡献值）。

规则：

- 现金一律按本公式分发；活动原设的奖项名目（如「最佳诗词」）保留为**荣誉头衔**，不改变现金分配。
- 贡献值为 0 的个人与阵营不参与分配。
- 无奖金活动（`P = 0`）不走现金分发，仅累计贡献与荣誉。

## 区长与邀请

- 每场活动中，**第一个加入某阵营的用户**可以选择成为该阵营的**区长**（可选，也可以只做普通成员）。
- 区长可生成专属邀请链接，在**活动期间任一阶段**分享（包括阵营选择阶段与正式阶段）。
- 被邀请者打开链接后只有两个选择：**接受并加入区长所在阵营**（需先登录），或**拒绝**邀请；拒绝后仍可正常自由报名。
- 每位被邀请者成功加入，区长获得 **+50 平台贡献值**（与算力券的「邀请新用户 +¥5/天」相互独立：算力券奖励面向所有邀请者，区长奖励只发给区长）。
- 区长身份在该活动内有效；阵营锁定规则不变。

## 荣誉系统：「数字杭州市民」勋章

活动结束后按以下规则把表现折算为**平台贡献值**（终身累计、跨活动相加）：

| 结算项 | 平台贡献值奖励 |
| --- | --- |
| 举办者 | 活动总贡献值 × 10% |
| 个人表现：活动内个人贡献前 10% | +200 |
| 个人表现：活动内个人贡献前 11–30% | +100 |
| 阵营表现：冠军阵营每位成员 | +150 |
| 阵营表现：亚军阵营每位成员 | +80（需 ≥2 个阵营有贡献） |
| 区长邀请：每位通过邀请链接加入的市民 | +50（奖励给区长） |
| 完赛：至少 1 份合格提交 | +50 |

「数字杭州市民」勋章**平台唯一**，按平台贡献值确定星级，**只升不降**，通过用户与平台活动的互动慢慢升级：

| 星级 | 门槛（平台贡献值） | 称号 |
| --- | --- | --- |
| ★1 | ≥ 0 | 初来市民 |
| ★2 | ≥ 500 | 常驻市民 |
| ★3 | ≥ 2,000 | 活跃市民 |
| ★4 | ≥ 6,000 | 共建市民 |
| ★5 | ≥ 15,000 | 荣誉市民 |

勋章与平台贡献值、活动履历在**个人主页**展示。

## 算力榜（平台总览）

算力榜汇总所有活动的贡献数据：

- 平台所有活动的**总贡献值**
- 各阵营贡献值及占比（全平台口径）
- **用户贡献值排行榜**（跨活动累计）
